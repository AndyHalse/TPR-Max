# VisiGate Pro - AWS Deployment Guide

## Production Environment Variables for AWS Secrets Manager

This document outlines all environment variables required for production deployment of VisiGate Pro on AWS, organized by AWS Secrets Manager best practices.

### 🔐 Critical Security Secrets (Store in AWS Secrets Manager)

These secrets **MUST** be stored in AWS Secrets Manager and accessed via IAM roles:

#### Database Secrets
```bash
# Neon Database Configuration
DATABASE_URL="postgresql://user:password@host:5432/database"
NEON_API_KEY="neon_api_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

# Multi-tenant database URLs (auto-generated by Neon API)
# Format: customer-{customerId}-db-url
# Example: customer-dev-customer-001-db-url="postgresql://..."
```

#### Authentication & Security
```bash
# Session Management (CRITICAL)
SESSION_SECRET="super-secure-random-string-min-32-chars"

# CSRF Protection
CSRF_SECRET="another-secure-random-string-for-csrf"

# JWT Secrets (if using JWT)
JWT_SECRET="jwt-signing-secret-key"
JWT_REFRESH_SECRET="jwt-refresh-signing-secret"
```

#### Third-Party API Keys

## 🛡️ Security Best Practices

### Secret Rotation Strategy

1. **Database Credentials**: Rotate every 90 days
2. **API Keys**: Monitor usage and rotate quarterly
3. **Session Secrets**: Rotate every 30 days (with blue-green deployment)
4. **JWT Secrets**: Coordinate rotation with session invalidation

### IAM Policy for Secrets Access

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "secretsmanager:GetSecretValue",
        "secretsmanager:DescribeSecret"
      ],
      "Resource": [
        "arn:aws:secretsmanager:region:account:secret:visigate/production/database/*",
        "arn:aws:secretsmanager:region:account:secret:visigate/production/auth/*",
        "arn:aws:secretsmanager:region:account:secret:visigate/production/external-apis/*"
      ]
    },
    {
      "Effect": "Allow",
      "Action": [
        "ssm:GetParameter",
        "ssm:GetParameters",
        "ssm:GetParametersByPath"
      ],
      "Resource": [
        "arn:aws:ssm:region:account:parameter/visigate/production/*"
      ]
    }
  ]
}
```

## 🚀 Deployment Checklist

### Pre-Deployment Security Verification

- [ ] All secrets stored in AWS Secrets Manager
- [ ] IAM roles configured with least-privilege access
- [ ] Environment variables never contain sensitive data
- [ ] Database connection strings use IAM authentication where possible
- [ ] All API keys are production-grade (not test/sandbox)
- [ ] CORS origins restricted to production domains only
- [ ] Rate limiting configured for production traffic levels

### Post-Deployment Verification

- [ ] Health check endpoints (`/livez`, `/readyz`, `/healthz`) responding
- [ ] CloudWatch logs showing structured JSON format
- [ ] Request IDs appearing in all log entries
- [ ] Database connections using connection pooling
- [ ] Session store using PostgreSQL (not memory)
- [ ] CSRF protection active on all state-changing routes
- [ ] Rate limiting blocking excessive requests
- [ ] Multi-tenant customer isolation working correctly

### Monitoring & Alerting Setup

1. **CloudWatch Alarms**:
   - Health check failures
   - High error rates (>5%)
   - Database connection pool exhaustion
   - Rate limiting triggers
   - Memory/CPU usage thresholds

2. **Log Monitoring**:
   - Security events (failed auth, CSRF violations)
   - Performance issues (slow queries >1s)
   - Business metrics (customer signups, visitor check-ins)
   - Error patterns and stack traces

3. **Business Metrics**:
   - Customer onboarding success rate
   - Average visitor processing time
   - Print job completion rates
   - System availability (99.9% target)

## 🔄 Disaster Recovery

### Database Backup Strategy
- Neon automatic backups every 24 hours
- Point-in-time recovery capability
- Cross-region backup replication
- Automated backup verification

### Application Recovery
- Blue-green deployment strategy
- Container health checks
- Auto-scaling based on CPU/memory
- Circuit breaker patterns for external APIs

### Data Protection
- All PII encrypted at rest and in transit
- Customer data isolation verification
- GDPR compliance for data deletion
- Audit trails for all data access
