
Replit Prompt — 2FA for Customer Login (TPR Max)
## Context
The platform admin login at `/platform-admin/login` already has a working two-step OTP 
(one-time password) flow. We need to implement the same pattern for the standard customer 
login at `client/src/pages/Login.tsx`.
---
## How the platform admin OTP works (copy this pattern)
In `server/routes/platformAdmin.ts` (lines 18–195):
- An in-memory Map `pendingOtps` stores `{ adminId, email, otp, expiresAt }` keyed by 
  a `pendingToken` (UUID).
- Step 1 — `POST /platform-admin/auth/login`: validates credentials, generates a 6-digit 
  OTP, stores it in `pendingOtps`, sends it via email, returns 
  `{ requiresOtp: true, pendingToken, maskedEmail }`. Does NOT create a session.
- Step 2 — `POST /platform-admin/auth/verify-otp`: accepts `{ pendingToken, otp }`, 
  validates it, then creates the session and returns the admin data.
In `client/src/pages/PlatformAdminLogin.tsx`:
- Uses `step` state (`"credentials"` | `"otp"`) to switch between two forms in the same Card.
- Step 1 form: username + password → calls login mutation.
- Step 2 form: 6-digit OTP input (numeric, tracking-widest font-mono style) → calls 
  verify-otp mutation.
- `maskedEmail` is shown as context: "A 6-digit code was sent to a****@domain.com"
- "Back to login" link resets to credentials step.

interface PendingCustomerOtp {
  userId: string;
  customerId: string;
  companyName: string;
  username: string;
  email: string;
  otp: string;
  expiresAt: Date;
}
const pendingCustomerOtps = new Map<string, PendingCustomerOtp>();
// Prune expired entries every 5 minutes
setInterval(() => {
  const now = new Date();
  for (const [key, val] of pendingCustomerOtps.entries()) {
    if (val.expiresAt < now) pendingCustomerOtps.delete(key);
  }
}, 5 * 60 * 1000);
function generateCustomerOtp(): string {
  return String(Math.floor(100000 + Math.random() * 900000));
}
function maskEmail(email: string): string {
  const [local, domain] = email.split('@');
  if (!domain) return email;
  const masked = local[0] + '*'.repeat(Math.max(local.length - 1, 3));
  return `${masked}@${domain}`;
}

4. Server — new route POST /api/auth/verify-2fa (server/routes/auth.ts)
Add this after the login route:

// Rate limit: 5 attempts per 15 minutes per IP
const twoFaLimiter = rateLimit({
  windowMs: 15 * 60 * 1000,
  max: 5,
  message: { error: 'Too many verification attempts. Try again in 15 minutes.' }
});

app.post('/api/auth/verify-2fa', twoFaLimiter, async (req, res) => {
  try {
    const { pendingToken, otp } = req.body;
    
    if (!pendingToken || !otp) {
      return res.status(400).json({ error: 'Verification code and token are required' });
    }
    
    const pending = pendingCustomerOtps.get(pendingToken);
    
    if (!pending) {
      return res.status(401).json({ error: 'Invalid or expired verification session. Please log in again.' });
    }
    
    if (new Date() > pending.expiresAt) {
      pendingCustomerOtps.delete(pendingToken);
      return res.status(401).json({ error: 'Verification code has expired. Please log in again.' });
    }
    
    if (otp.trim() !== pending.otp) {
      return res.status(401).json({ error: 'Incorrect verification code. Please check your email and try again.' });
    }
    
    // Valid — consume the token
    pendingCustomerOtps.delete(pendingToken);
    
    // Reconstruct user and customer objects for session creation
    const user = { id: pending.userId, username: pending.username, email: pending.email };
    const customer = { id: pending.customerId, companyName: pending.companyName };
    
    await createCustomerSession(req, res, user, customer, pending.username);
  } catch (error) {
    logger.error('2FA verification error:', error);
    res.status(500).json({ error: 'Verification failed' });
  }
});

const handleOtpSubmit = async (e: React.FormEvent) => {
  e.preventDefault();
  setOtpError('');
  setIsLoading(true);
  try {
    const response = await fetch('/api/auth/verify-2fa', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ pendingToken, otp: otpValue }),
      credentials: 'include',
    });
    const data = await response.json();
    if (response.ok && data.success) {
      // Same post-login handling as existing successful login
      // (store rememberMe, set auth cache, apply branding, navigate)
      if (rememberMe) {
        localStorage.setItem('tprmax-remember-me', 'true');
        localStorage.setItem('tprmax-last-login', JSON.stringify(credentials));
      } else {
        localStorage.removeItem('tprmax-remember-me');
        localStorage.removeItem('tprmax-last-login');
      }
      if (data.logoToken) localStorage.setItem('tprmax-logo-token', data.logoToken);
      queryClient.setQueryData(['/api/auth/me'], data.user);
      if (data.settings) {
        queryClient.setQueryData(['/api/settings'], data.settings);
        applyBrandingFromSettings(data.settings);
      }
      setLocation(data.user.defaultLandingPage || '/');
    } else {
      setOtpError(data.error || 'Invalid verification code');
      setOtpValue('');
    }
  } catch {
    setOtpError('Network error. Please try again.');
  } finally {
    setIsLoading(false);
  }
};
