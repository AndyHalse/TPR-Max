Context
-------
The Fire Risk Assessment route file (server/routes/fireRiskAssessment.ts) builds SQL
queries using manual string concatenation and quote-escaping instead of parameterised
queries. This is inconsistent with the rest of the codebase and creates unnecessary risk.
There are four locations to fix — listed below in order. Do not change anything else in
the file: no logic, no feature behaviour, no error handling.

The pattern used by HR routes for raw SQL (which you should follow) is:
  const pool = (custDb as any).$client ?? (custDb as any).session?.client;
  await pool.query(`SELECT ... WHERE id = $1`, [someId]);
