## FIX 1 — Mobile video display (CRITICAL — fix this first)

File: client/src/pages/SiteInduction.tsx (or wherever the induction 
public page lives — search for "blob" and "createObjectURL")

The video content is delivered as a Blob URL loaded into an iframe. 
The iframe height calculation is broken on mobile.

Current problem pattern (find and fix):
- The parent container uses padding like `pt-[40px]` for a header bar
- The iframe uses `h-[calc(100%-40px)]` to account for that header
- On mobile, this fails because viewport height is not applied 
  consistently — the iframe collapses to near-zero height

FIXES:

a) Find the video iframe element. Replace its height approach:
   - Remove `h-[calc(100%-40px)]` 
   - Set the parent container to `flex flex-col` with `h-screen` 
     (or `h-[100dvh]` to handle iOS Safari's dynamic viewport)
   - Set the iframe to `flex-1 min-h-0 w-full` so it fills all 
     remaining space after the header bar

b) The header/controls bar above the iframe should be a fixed-height 
   flex row: apply `flex-shrink-0` so it never compresses

c) The bottom controls bar (Previous / Pause / Next buttons) — if it 
   is inside the iframe HTML itself, leave it alone. If it is outside 
   the iframe in React, apply `flex-shrink-0` to it as well.

d) On the fullscreen mode (when videoFullscreen === true):
   - Container: `fixed inset-0 z-50 bg-black flex flex-col`
   - Iframe: `flex-1 min-h-0 w-full border-0`
   This ensures fullscreen also works correctly on mobile.

e) Test the layout at these viewport widths: 375px (iPhone SE), 
   390px (iPhone 14), 414px (iPhone Plus). The slide content area 
   must be visible at all three sizes.

## FIX 2 — Blob URL memory leak

In the same SiteInduction.tsx file, find where the Blob URL is 
created:
  const blob = new Blob([videoHtml], { type: 'text/html' });
  const url = URL.createObjectURL(blob);

This URL is never revoked when the component unmounts, causing a 
memory leak. Fix:

Store the blob URL in a useRef or useState. Add a useEffect with 
a cleanup function that calls URL.revokeObjectURL() when the 
component unmounts or when the videoHtml changes:

  useEffect(() => {
    if (!videoHtml) return;
    const blob = new Blob([videoHtml], { type: 'text/html' });
    const url = URL.createObjectURL(blob);
    setVideoBlobUrl(url);
    return () => URL.revokeObjectURL(url);
  }, [videoHtml]);

## FIX 3 — Quiz attempt rate limiting

File: server/routes/induction.ts

Find the POST endpoint for quiz submission (search for 
"submit-quiz"). Currently there is no rate limiting — a user 
could brute-force all answers.

Add this guard at the top of the handler, before any answer 
processing:

1. Fetch the current token record
2. If quizAttempts >= 3, return HTTP 429 with JSON:
   { error: "Maximum quiz attempts reached. Please contact the 
     site administrator to reset your induction." }
3. If the last attempt was within the past 10 minutes, return 
   HTTP 429 with JSON:
   { error: "Please wait 10 minutes before retrying the quiz." }
   (Use quizCompletedAt or add a lastAttemptAt field if needed)
