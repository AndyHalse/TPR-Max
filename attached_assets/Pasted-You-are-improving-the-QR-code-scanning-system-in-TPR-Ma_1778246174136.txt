────────────────────────────────────────────────────────────────────

better in low light, reads more code formats (QR, Code 128, Code 39,

Install: npm install @zxing/library

Replace all jsQR decode calls with ZXing BrowserMultiFormatReader. 
Key change:

  // ZXing handles both inversions automatically and reads more formats

Remove jsqr from package.json dependencies after migration.

PRIORITY 3 — AUDIO FEEDBACK
────────────────────────────────────────────────────────────────────

FILE: All scanner components

Add a short beep on successful scan using the Web Audio API (no 
external sound file needed):

  function playBeep() {
    const ctx = new AudioContext()
    const osc = ctx.createOscillator()
    const gain = ctx.createGain()
    osc.connect(gain)
    gain.connect(ctx.destination)
    osc.frequency.value = 1800
    gain.gain.setValueAtTime(0.3, ctx.currentTime)
    gain.gain.exponentialRampToValueAtTime(0.001, ctx.currentTime + 0.15)
    osc.start(ctx.currentTime)
    osc.stop(ctx.currentTime + 0.15)
  }

Call playBeep() immediately when a QR code is first detected (before 
the API call completes). This gives instant feedback — the same UX 
used by supermarket checkouts and warehouse scanners.

PRIORITY 3 — SCAN RETRY ON API FAILURE
────────────────────────────────────────────────────────────────────

FILE: All scanner components

Currently if the POST to the API fails (network blip, server error), 
the scan is silently lost and the scanner just returns to idle. 
The user has no idea the sign-in failed.

FIX: Add retry logic with visible feedback:

  async function submitScan(data: string, attempt = 1) {
    try {
      const res = await fetch(endpoint, { method: 'POST', body: ... })
      if (!res.ok) throw new Error(`HTTP ${res.status}`)
      // handle success
    } catch (err) {
      if (attempt < 3) {
        await delay(500 * attempt)  // exponential backoff
        return submitScan(data, attempt + 1)
      }
      // After 3 failures: show error state with "Try again" button
      setState('error')
      setErrorMessage('Could not connect. Please try again or sign in manually.')
    }
  }
